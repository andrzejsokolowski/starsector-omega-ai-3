Relevant entries included AI Tweaks 2.2.10, RTSAssist 0.1.9c, StopStackingMe 1.0.2, Star Wars Combat AI 1.01, and Vanilla Weapon Rebalance 1.1.0.

The saved AI Tweaks configuration read after the battle had `aitweaks_enable_fleet_cohesion_ai` set to `true`.
That file's modification time was 01:30:16 local time.
Omega's guard blocks Coordinate orders while this option is enabled.
The current saved Omega configuration already said Coordinate, with a modification time of 01:38:36.
That later configuration does not change the Observe mode recorded during the completed battle.

The fleet-cohesion conflict does not, by itself, explain the zero proposals.
Observation still runs with that conflict, while the conflict blocks order application.
However, existing assignments, custom controllers, and the other eligibility checks can exclude ships before planning.
The log omits eligibility counts, controller identities, and exclusion reasons.
It also omits the target and position history needed to determine whether any regrouping rule applied.
The current record cannot distinguish an unnecessary intervention from a planner that never received an eligible ship.
